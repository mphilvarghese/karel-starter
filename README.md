Karel the Robot - Starter Program Description - Mathew Varghese - Texas Christian University - COSC 10001 

This repository is a reflection of the work I have completed in COSC 10001 at Texas Christian University (TCU) with Professor Bingyang Wei. 
It is important to note that Karel is a robot that is only able to operate using four commands. 

In order to run the program: 

1. The folder containing the program should be opened using IntelliJ
2. The green start on IntelliJ can be pressed to start the program.
(Alternatively, the command run.ps1 can be run on Intelli's terminal for Windows devices to execute this program. )
(For macOS, the command to run the program is run.sh).

Through this program, I learned: 

- The importance of focusing on every step in a program to make the robot does what it is required to do and does not miss any of them or execute them improperly.
- How to create Java methods to enable the robot to carry out more actions than it previously could.
- How to code using Java specific syntax as I have never learned how to create coded programs using Java.
